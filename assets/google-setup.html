Google Cloud setup

Create OAuth credentials so Orbit can read your calendars.

Steps

  1. Open Google Cloud Console and create or select a project.
  2. Enable the Google Calendar API for that project.
  3. Configure the OAuth consent screen (External is fine for personal use; add yourself as a test user if in Testing mode).
  4. Create an OAuth 2.0 Client ID → Application type: Desktop app (or Web application if you prefer).
  5. Add this Authorized redirect URI:
    http://localhost:3000/oauth2callback
  6. Copy the Client ID and Client secret into Orbit Settings → Google.
  7. Click Save, then Connect on each account (Primary, Personal, Work) you need.

Redirect URI must match exactly what you enter in Settings. Orbit runs a local server on port 3000 during sign-in. Tokens are saved per account in your config folder (e.g. credentials-personal.json).
